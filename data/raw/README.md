# data/raw/

This directory is where `scripts_build/build_corpus.py --real` would
leave a copy of the downloaded OSCAR Corpus Nepali raw file, if run on a
machine with internet access to Kaggle. In this project's actual run
(`--synthetic` mode), nothing is downloaded, so this directory is empty;
`data/processed/` holds the generated synthetic train/val/test splits
instead. See the project root `README.md` for details.
